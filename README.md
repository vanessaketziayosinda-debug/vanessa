# Vanessa Ketzia Yosinda — Portfolio

Portfolio website statis, responsif, dan tanpa framework.

## Struktur
- `index.html` — isi halaman
- `style.css` — desain/responsif
- `script.js` — menu mobile & tahun footer
- `assets/profile.jpg` — foto profil

## Cara menjalankan
Cukup buka `index.html` di browser.

## Deploy gratis
Project ini cocok untuk hosting static seperti Netlify, GitHub Pages, atau Cloudflare Pages.
Tidak membutuhkan database/backend untuk versi ini.

## Yang perlu kamu edit nanti
1. Tambahkan link GitHub ketika sudah siap.
2. Tambahkan link demo AIRA HUB/POSMart ketika website sudah online.
3. Tambahkan screenshot project agar portfolio makin kuat.
4. Tambahkan CV sebagai tombol download jika ingin.

Catatan: konten project ditulis berdasarkan informasi yang tersedia dan sebaiknya disesuaikan lagi dengan status project sebenarnya sebelum dipublikasikan.
